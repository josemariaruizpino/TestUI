Guía de uso

✔️ Forma correcta

  • Usar siempre e-btn + variante
  • Usar "<button>" para acciones y "<a>" para navegación
  • Mantener textos claros y accionables

❌ Usos prohibidos

  • No usar solo e-btn sin variante
  • No mezclar varias variantes
  • No usar .disabled sin controlar la lógica en JS

⚠️ Importante:

  • Se usa clase .disabled (no el atributo disabled)
  • Cambia estilos visuales
  • No bloquea comportamiento JS automáticamente, AÑADIR el atributo para bloquearlo
