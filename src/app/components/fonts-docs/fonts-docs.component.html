Utilidades CSS para controlar las fuentes y tipografías. Todas las clases soportan el sistema responsive con los mismos breakpoints definidos en Settings.

Fonts utilities

✔️ Forma correcta

  • Usar las clases utilitarias en lugar de estilos en línea para font-size, font-weight y text-align.
  • Combinar clases responsive para adaptar la tipografía en distintas resoluciones: .u-fs-14 .u-fs-md-16.
  • Usar el sufijo xs como base mobile-first y sobrescribir con breakpoints mayores.
  • Usar .u-fw-600 o .u-fw-700 para destacar títulos y etiquetas.

❌ Usos prohibidos

  • No escribir font-size, font-weight ni text-align en línea si existe la clase utilitaria equivalente.
  • No crear clases ad-hoc para tamaños o pesos que ya están definidos en el mapa.
  • No añadir valores fuera de $px-map, $fw-map o $ta-map sin actualizar las variables del sistema.
