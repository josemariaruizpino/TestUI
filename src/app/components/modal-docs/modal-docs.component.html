Guía de uso

Estructura básica:

Elemento / Clase Descripción
.c-modalContenedor principal del modal. Controla dimensiones, fondo y posicionamiento.
.c-modal[open]Estado visible del modal. Se muestra centrado y ajustado al viewport.
.c-modal::backdropCapa de fondo semitransparente que oscurece el contenido.
.c-modal__contentContenedor interno del contenido del modal (texto, imágenes, botones, etc.).
.c-modal__headcontainerAgrupa título y subtítulo del modal.
.c-modal__titleTítulo principal del modal. Tipografía y tamaño adaptativos.
.c-modal__subtitleSubtítulo o descripción corta.
.c-modal__maincontentÁrea principal del contenido (scrollable si es extenso).
.exitBotón para cerrar el modal.
.exit-iconÍcono SVG o imagen dentro del botón de salida.

✔️ Forma correcta

  • Usar el elemento nativo <dialog> para mejorar accesibilidad y rendimiento.
  • Usar command="show-modal" y commandfor para abrir el modal.
  • Usar command="close" en el botón de cierre.
  • Añadir closedby="any" para cerrar al hacer clic fuera o pulsar Esc.

❌ Usos prohibidos

  • No sustituir <dialog> por div con JS para imitar su comportamiento.
  • No omitir el botón de cierre .exit.
  • No usar el modal sin closedby si se quiere soporte de cierre por backdrop.
