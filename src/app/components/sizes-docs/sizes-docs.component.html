Sizes & Spaces

Utilidades CSS para controlar dimensiones y espaciado. Organizadas en dos archivos: sizes.scss para altura y ancho, y spaces.scss para márgenes y paddings.

Altura y ancho

Define altura (height) y ancho (width) con valores fijos en píxeles o porcentuales. Las clases siguen el patrón .u-{propiedad}-{valor} y admiten un modificador de breakpoint opcional .u-{propiedad}-{bp}-{valor}.

Breakpoints disponibles:

Sufijo Breakpoint Descripción
smmin-width: 768pxTablet en adelante
mdmin-width: 992pxEscritorio pequeño
lgmin-width: 1224pxEscritorio grande

Ejemplos de uso:

Clase CSS generado Uso típico
.u-height-32 height: 32px !important Altura fija de un icono o avatar
.u-height-48 height: 48px !important Altura estándar de un botón o input
.u-width-100 width: 100% !important Elemento que ocupa todo el ancho del contenedor
.u-width-50 width: 50% !important Mitad del contenedor padre
.u-height-lg-40 @media (min-width: 1224px) { height: 40px !important } Altura diferente sólo en pantallas grandes
.u-width-sm-80 @media (min-width: 768px) { width: 80% !important } Ancho reducido a partir de tablet

✔️ Forma correcta

  • Usar .u-width-100 para que un elemento ocupe todo el ancho disponible.
  • Combinar con breakpoints para adaptar dimensiones según el viewport.
  • Aplicar sobre elementos concretos donde el tamaño debe ser fijo o controlado.

❌ Usos prohibidos

  • No usar si el tamaño debe derivarse del contenido o del layout (flexbox/grid).
  • No combinar .u-height-* con min-height inline sin control explícito.

Márgenes y paddings

Permite establecer márgenes y paddings en todas las direcciones. Las clases siguen el patrón .u-{propiedad}{dirección}-{valor} y admiten breakpoint con .u-{propiedad}{dirección}-{bp}-{valor}.

Direcciones disponibles:

Sufijo Propiedad Aplica a
ningunomargin / paddingLos 4 lados
tmargin-top / padding-topSuperior
bmargin-bottom / padding-bottomInferior
smargin-inline-start / padding-inline-startInicio lógico (izquierda en LTR)
emargin-inline-end / padding-inline-endFin lógico (derecha en LTR)
xmargin-left + right / padding-left + rightEje horizontal
ymargin-top + bottom / padding-top + bottomEje vertical

Ejemplos de uso:

Clase CSS generado Uso típico
.u-m-16 margin: 16px !important Margen uniforme alrededor del elemento
.u-mt-8 margin-top: 8px !important Separación superior entre secciones
.u-mb-24 margin-bottom: 24px !important Espaciado inferior de un bloque
.u-px-12 padding-left: 12px !important; padding-right: 12px !important Relleno horizontal en botones o chips
.u-py-8 padding-top: 8px !important; padding-bottom: 8px !important Relleno vertical en filas de tabla
.u-mx-auto margin-left: auto !important; margin-right: auto !important Centrado horizontal de un bloque
.u-my-md-24 @media (min-width: 992px) { margin-top: 24px !important; margin-bottom: 24px !important } Separación vertical mayor en escritorio
.u-ps-16 margin-inline-start: 16px !important Sangría de inicio compatible con RTL

✔️ Forma correcta

  • Usar .u-mx-auto para centrar horizontalmente elementos de ancho fijo.
  • Combinar dirección y breakpoint: .u-mt-md-24 para separación superior sólo en escritorio.
  • Preferir .u-px-* y .u-py-* sobre .u-p-* cuando el espaciado no es uniforme.

❌ Usos prohibidos

  • No usar .u-m-* para crear separación entre componentes hermanos; usar gap en el contenedor.
  • No acumular múltiples clases de margen en el mismo eje sin verificar que no se solapan.
