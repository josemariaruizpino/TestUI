Guía de uso

✔️ Forma correcta

  • Usar el elemento nativo <details> con el <summary> como trigger.
  • Mantener la estructura BEM: .e-summary, .e-summary__trigger, .e-summary__title, .e-summary__icon y .e-summary__content.
  • Aplicar .e-summary--secondary cuando se quiera enfatizar el desplegable.

❌ Usos prohibidos

  • No sustituir <details> por div con JS para imitar su comportamiento.
  • No anidar varios <summary> dentro del mismo <details>.
  • No quitar el icono indicador (.e-summary__icon) que comunica el estado.
